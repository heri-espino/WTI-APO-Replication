# Contributing

1. Review README.md, AGENTS.md, HANDOFF.md, the release manifest and open PRs before changing files.
2. Work in a narrow branch. Never import private Git history, restricted market data, confidential paths, credentials or unapproved derivatives.
3. Run `python -m pip install -e ".[dev]"`, `python -m pytest -q`, the public-file guard and metadata checks.
4. Add scientific documentation and provenance alongside reviewed code, tests, configuration, synthetic fixtures, permitted results and experiments.
5. Open a PR. **No merge or GitHub/Zenodo release without explicit author authorization.**
6. For future studies use sequential experiment names, documented seeds, commands, uncertainty and next steps.

MIT covers original public files only; vendor-owned data and private software require their own rights review.
